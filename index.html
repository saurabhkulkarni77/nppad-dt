TRY THE AI: WHAT DOES IT THINK IS HAPPENING?

This page runs a real AI model in your browser. The model was trained to look at one minute of sensor readings from a nuclear plant and say which accident is happening. Pick a recorded accident below, press RUN THE AI, and see its answer, how sure it is, and whether it was right.

WHAT IS LIVE HERE, IN PLAIN WORDS. One model, called MultiRocket+HYDRA, really runs in your browser when you press RUN THE AI. It is the same model the study built to ride on the plant's own small computer, and before this site was published it was checked against the study's reference version on every scenario on this page; the check result is in the status line below. The other seven study models do not run live here. Their answers, recorded during the study for this exact same minute of data, are shown on the right so you can compare. The time the model takes is measured in your browser, as it runs.

IT WORKS WITH NO LINK AT ALL

Cut the link to Earth with the button above and run again. The answer is exactly the same, because the AI never used the link. That is the whole idea: the decision is made where the accident happens, not on a faraway Earth that takes minutes to answer.

IT TAKES THE SAME TIME EVERY RUN

The model does the same fixed set of steps for every window, so it costs the same small amount of time each time. The time you measure here is the same task the plant computer would run; its speed on a single processor core is listed on the "What we learned" page.

WHAT IT CANNOT DO

The AI only knows the 12 accident types it was taught. Try the "normal operation" or "before the accident" scenarios and watch: shown data outside those 12, it still picks one of them. A real plant would also need a separate guard that can say "nothing is wrong" or "this is new to me". And the confidence number is a way of ranking its guesses, not a true probability.
