RESULTS: EVERY TRAINED MODEL, EVERY SETTING

This page is the study's full trained-model record: the eight core models (LogReg, LogReg+, Random Forest, CNN, GRU, MultiRocket+HYDRA, Rocket and MiniRocket), scored on the same held-out test windows under many settings, plus the Transformer arm added later. Filter the main grid by when the window starts, how long it is, and which sensors the model may see. Below the grid you can look up what each model predicted for one exact test window, and read the extension, robustness and detection studies.

THE MAIN GRID

Macro F1 is the headline score: the average of the per-accident scores, so a model cannot look good by only spotting the easy accidents. Validation F1 was measured on the separate validation split and was used to pick settings; the test columns are the held-out final word.

THE WINDOW ITSELF CHANGES THE ANSWER (E5)

Same models, same start, but the window length W varies. Short windows starve the model; the study's headline setting is W = 60 s.

THE TRANSFORMER ARM (ADDED 2026-11-11)

Trained under the exact study protocol (same split, same summary features) with three seeds; the numbers shown are the seed means of the probability-averaged scores. Its per-accident F1 scores are in the detail line under the table.

Twenty seconds in, most accidents still look like normal operation, so every model lands near the same low score. These rows were recomputed from the recorded per-window prediction files themselves, and this page's window lookup above uses those same files.

WHERE THESE NUMBERS COME FROM. Every number on this page is read at build time from the study's own result files by tools/generate_study_data.py, which also recomputes the per-model scores from the recorded prediction files and checks them against the study's tables before writing anything. Nothing here is typed in by hand.
